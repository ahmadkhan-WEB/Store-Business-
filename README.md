Nordly: One-Page Business Website

A responsive one-page business website built with HTML, CSS, and vanilla JavaScript. No frameworks or build tools are needed.

Features
Responsive layout: media queries for phones, tablets, and desktops
Mobile menu: hamburger menu that closes when you tap a link or click outside, and resets automatically when the screen is resized
Active navigation: the current section is highlighted in the menu as you scroll
Tabs: switch between content panels without reloading the page
Touch-friendly: larger tap targets on small screens
Motion preferences: animations respect the prefers-reduced-motion setting
Tech Stack
HTML5
CSS3 (Flexbox, Grid, media queries, CSS variables)
JavaScript (ES6+)
Project Structure
├── index.html   # Page structure and content
├── style.css    # Styling and responsive layout
├── script.js    # Menu, tabs, and scroll navigation
└── files/       # Images used by the page
Run Locally
Download or clone the repository
Make sure the image files used by the page are in the same folders as in index.html
Open index.html in any browser
